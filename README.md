# BLONDA Portal för Mac

Ladda ner appen på **https://blonda.studio/app**.

Det här repot innehåller bara färdiga versioner av appen (under Releases), ingen
källkod. Nya versioner läggs upp automatiskt varje timme från BLONDAs
leveransportal, och appen uppdaterar sig själv när den väl är installerad.
